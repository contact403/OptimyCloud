4. Sample detailed sheet: recommendation no. 1

Finding. Production pods pull their images from ECR and write their exports to S3. This traffic goes out through the NAT Gateways and pays NAT processing on every gigabyte (about $0.045/GB in the Paris region), roughly 20 TB per month.

Action. Add a gateway VPC endpoint for S3 (no processing fees) and interface endpoints for ECR (api and dkr). No application changes.

Estimated savings. About €850/month net, after the hourly cost of the interface endpoints. How to check: the "NatGateway-Bytes" line in Cost Explorer, 7 days after deployment.

Excerpt from the pull request provided

+resource "aws_vpc_endpoint" "s3" {
+  vpc_id            = module.vpc.vpc_id
+  service_name      = "com.amazonaws.eu-west-3.s3"
+  vpc_endpoint_type = "Gateway"
+  route_table_ids   = module.vpc.private_route_table_ids
+}
+
+resource "aws_vpc_endpoint" "ecr" {
+  for_each            = toset(["ecr.api", "ecr.dkr"])
+  vpc_id              = module.vpc.vpc_id
+  service_name        = "com.amazonaws.eu-west-3.${each.key}"
+  vpc_endpoint_type   = "Interface"
+  subnet_ids          = module.vpc.private_subnets
+  security_group_ids  = [aws_security_group.endpoints.id]
+  private_dns_enabled = true
+}

60 days after delivery, we compare the actual bill with the estimates together, item by item, using Cost Explorer. Any gaps are explained (recommendation not applied, higher usage, and so on). This comparison is included in the price.

7. Method and limitations

  • Sources: Cost Explorer (3 months), resource inventory, CloudWatch metrics, through the published read-only role.
  • Savings are estimates at constant usage, based on public pricing at the date of the audit.
  • No changes are made to the account: all changes go through your pull requests and your approval.
