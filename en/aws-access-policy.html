AWS access policy for the FinOps Sprint

This is exactly what we ask for to audit your AWS bill. Read it, have your security team review it, and remove anything you are not comfortable with: you create the role yourself.

What the role allows

Reading billing data (Cost Explorer, Savings Plans, budgets, AWS recommendations), listing resources (instances, volumes, databases, clusters, NAT, load balancers, buckets) and reading their CloudWatch metrics.

What it denies

Reading the content of your S3 buckets, your secrets, SSM parameters, logs, DynamoDB tables, Lambda code and environment variables, EC2 user data. No write action is granted.

Before the audit: no access at all

The free pre-diagnostic only uses a Cost Explorer export (CSV) that you send us. The role below is only created once the audit is ordered and the NDA signed.

1. Permissions policy

Read-only, actions listed one by one (no generic ec2:Describe*, which would expose user data). An explicit Deny block also closes access to data and secrets, even if another policy attached to the role allowed it.

The bill is analysed through Cost Explorer (including resource-level granularity if you have enabled it). The role does not read Cost and Usage Report files stored in S3: if you use the CUR and want a finer analysis, you can send us an export yourself.

2. Trust policy

Only OptimyCloud's AWS account can assume the role, and only with the unique ExternalId we give you at kick-off. This protects against the "confused deputy" problem.

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": { "AWS": "arn:aws:iam::OPTIMYCLOUD_ACCOUNT_ID:root" },
      "Action": "sts:AssumeRole",
      "Condition": {
        "StringEquals": { "sts:ExternalId": "YOUR_UNIQUE_EXTERNAL_ID" }
      }
    }
  ]
}

3. Create and revoke the role

  1. IAM console → Roles → Create role → "Another AWS account", with the account ID and ExternalId we send you.
  2. Create a custom policy with the JSON from step 1 and attach it to the role (suggested name: OptimyCloudFinOpsAudit).
  3. Send us the role ARN. The audit starts: 7 business days.
  4. At the end of the audit, delete the role. You can also delete it at any time: access stops immediately.
