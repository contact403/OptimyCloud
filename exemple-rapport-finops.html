4. Exemple de fiche détaillée : recommandation n° 1

Constat. Les pods de production téléchargent leurs images depuis ECR et écrivent leurs exports dans S3. Ce trafic sort par les NAT Gateways et paie le traitement NAT à chaque gigaoctet (environ 0,045 $/Go en région Paris), soit environ 20 To par mois.

Action. Ajouter un VPC endpoint de type gateway pour S3 (sans frais de traitement) et des endpoints de type interface pour ECR (api et dkr). Aucun changement applicatif.

Gain estimé. Environ 850 €/mois net, après le coût horaire des endpoints interface. Comment vérifier : ligne « NatGateway-Bytes » de Cost Explorer, 7 jours après le déploiement.

Extrait de la pull request fournie

+resource "aws_vpc_endpoint" "s3" {
+  vpc_id            = module.vpc.vpc_id
+  service_name      = "com.amazonaws.eu-west-3.s3"
+  vpc_endpoint_type = "Gateway"
+  route_table_ids   = module.vpc.private_route_table_ids
+}
+
+resource "aws_vpc_endpoint" "ecr" {
+  for_each            = toset(["ecr.api", "ecr.dkr"])
+  vpc_id              = module.vpc.vpc_id
+  service_name        = "com.amazonaws.eu-west-3.${each.key}"
+  vpc_endpoint_type   = "Interface"
+  subnet_ids          = module.vpc.private_subnets
+  security_group_ids  = [aws_security_group.endpoints.id]
+  private_dns_enabled = true
+}

7. Méthode et limites

  • Sources : Cost Explorer (3 mois), inventaire des ressources, métriques CloudWatch, via le rôle en lecture seule publié.
  • Les gains sont des estimations à usage constant, aux tarifs publics à la date de l'audit.
  • Aucune modification n'est faite sur le compte : les changements passent par vos pull requests et votre validation.
