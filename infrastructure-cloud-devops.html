Questions fréquentes

AWS, GCP ou Azure : quel cloud choisir ?

Les trois fournisseurs couvrent les besoins d'une PME. Le choix dépend surtout de votre contexte : les compétences de votre équipe, les outils déjà en place (un parc Microsoft 365 et Entra ID oriente souvent vers Azure, un usage avancé de BigQuery vers GCP), les services managés dont vous avez besoin et vos contraintes de localisation des données. AWS reste le plus large en catalogue et c'est mon expertise principale, mais je recommande le cloud qui vous convient, pas celui que je préfère.

Comment limiter l'interruption de service pendant une migration ?

La nouvelle infrastructure est construite et testée en parallèle de l'existante. Les données sont synchronisées en continu quand c'est possible (réplication de base de données, copie incrémentale des fichiers), puis la bascule se fait application par application, sur un créneau choisi avec vous, avec un plan de retour arrière écrit à l'avance. La durée d'interruption dépend de chaque application et de sa base de données ; elle est estimée pendant la phase de conception, avant de s'engager.

Kubernetes est-il adapté à une PME ?

Pas toujours. Pour quelques applications simples, des services comme ECS, Cloud Run, App Runner ou une VM bien automatisée suffisent et coûtent moins cher à exploiter. Kubernetes devient intéressant quand vous avez plusieurs services conteneurisés, plusieurs équipes ou des besoins de montée en charge. Les offres managées comme EKS Auto Mode réduisent beaucoup la charge d'exploitation. En tant que consultant Kubernetes certifié CKA, je vous dirai franchement si c'est le bon outil pour vous.

Qu'apporte concrètement l'infrastructure as code avec Terraform ?

Votre infrastructure devient du code versionné dans Git : chaque modification est relue avant d'être appliquée, l'historique montre qui a changé quoi et pourquoi, et un environnement complet peut être recréé à l'identique. Cela supprime les configurations faites à la main dans la console, facilite les audits de sécurité et rend la reprise après incident beaucoup plus rapide. Terraform fonctionne sur AWS, GCP et Azure ; AWS CDK est une bonne option si vous êtes 100 % AWS et que votre équipe préfère TypeScript ou Python.

Travaillez-vous avec nos équipes internes ?

Oui, c'est le cas le plus fréquent. Je m'intègre à vos outils (Git, tickets, messagerie) et à vos rituels, je travaille en binôme avec vos développeurs ou votre équipe d'exploitation et je documente au fil de l'eau. L'objectif est que votre équipe soit autonome sur ce qui a été construit. Je peux aussi intervenir seul si vous n'avez pas encore de compétence infrastructure en interne.
